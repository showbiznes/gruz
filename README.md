# 🚀 Discord Бот — Оповещение о сбросе груза

Бот автоматически оповещает участников сервера о сбросе груза в заданное время по МСК с тегом `@everyone`.

## ⏰ Расписание оповещений (МСК)

| Время | Событие |
|-------|---------|
| 00:00 | Сброс груза |
| 12:00 | Сброс груза |
| 16:00 | Сброс груза |
| 21:30 | Сброс груза |

## 📋 Команды бота

| Команда | Описание |
|---------|----------|
| `!расписание` | Показывает расписание сбросов |
| `!время` | Показывает текущее московское время |
| `!тест` | Тестовое оповещение (только админ) |

## 🛠 Настройка

### 1. Создание бота в Discord

1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications)
2. Нажмите **New Application** → введите имя → **Create**
3. Перейдите в раздел **Bot** → нажмите **Add Bot**
4. Скопируйте **Token** (нажмите **Reset Token** если нужно)
5. Включите **MESSAGE CONTENT INTENT** в разделе Privileged Gateway Intents
6. В разделе **OAuth2 → URL Generator**:
   - Scopes: `bot`
   - Bot Permissions: `Send Messages`, `Mention Everyone`
7. Скопируйте сгенерированный URL и откройте его в браузере для добавления бота на сервер

### 2. Получение ID канала

1. В Discord: **Настройки** → **Расширенные** → включите **Режим разработчика**
2. Правой кнопкой по нужному каналу → **Копировать ID**

### 3. Настройка `.env`

Отредактируйте файл `.env`:

```env
DISCORD_TOKEN=ваш_токен_бота
CHANNEL_ID=id_вашего_канала
```

### 4. Локальный запуск

```bash
pip install -r requirements.txt
python bot.py
```

## 🌐 Деплой на bothost.ru

### Шаг 1 — Регистрация
Зарегистрируйтесь на [bothost.ru](https://bothost.ru)

### Шаг 2 — Создание проекта
1. В личном кабинете нажмите **Создать бота** (или **Новый проект**)
2. Выберите язык: **Python**

### Шаг 3 — Загрузка файлов
Загрузите на хостинг следующие файлы:
- `bot.py` — основной файл бота
- `requirements.txt` — зависимости

### Шаг 4 — Переменные окружения
В настройках проекта на bothost.ru задайте переменные окружения:
- `DISCORD_TOKEN` = ваш токен бота
- `CHANNEL_ID` = ID канала для оповещений

> ⚠️ **Не загружайте файл `.env` на хостинг!** Используйте встроенные переменные окружения хостинга.

### Шаг 5 — Запуск
1. Убедитесь, что в настройках указан главный файл: `bot.py`
2. Нажмите **Запустить**
3. Проверьте логи — бот должен написать «Бот запущен и готов к работе!»
